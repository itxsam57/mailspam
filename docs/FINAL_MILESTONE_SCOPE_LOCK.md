# Final Milestone Scope Lock

The final milestone intentionally includes every remaining repository-buildable consumer capability identified by the canonical roadmap reconciliation, the recovered Email Shield product goal, the current code audit and the public competitor behavior benchmark.

New ideas discovered during implementation may be added to this same milestone only when they materially improve scam protection, privacy, family safety, consumer usability, inbox/account health or cross-platform readiness and can be implemented without weakening existing invariants.

Native packaging remains after milestone completion; it is not a reason to defer shared-engine work that native clients need.
