# Competitive Implementation Rule

Email Shield may study and independently reproduce useful publicly observable product behavior such as real-time warnings, explanation patterns, sensitivity controls, scam-check inputs, family safety workflows, sender screening, campaign alerts and browser/SMS protection.

Email Shield must not copy competitor source code, private APIs, private models, private datasets, trade secrets, branding, wording, UI assets or non-public implementation details.

When a competitor publicly claims a detection technique (for example full-context analysis, on-device processing, URL reputation, pattern recognition or AI-assisted classification), Email Shield must implement its own independently designed mechanism using the existing local-first portable engine, documented evidence provenance and privacy boundaries.

Competitive parity claims require our own tests. A competitor marketing claim is never accepted as evidence that Email Shield has equivalent accuracy.
